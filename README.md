# TonyDefence

Tower defense co-op in quattro ambientazioni. Qui ci sono solo le app da scaricare; il gioco si prova anche nel browser su https://tonydefence.bais.info.

- **Windows**: `TonyDefence-Setup-x.y.z.exe` si installa e si aggiorna da solo; `TonyDefence-x.y.z-portatile.exe` gira senza installazione.
- **Android**: `TonyDefence-x.y.z.apk`. Alla prima installazione Android chiede di consentire le app da questa fonte.

Scarica l'ultima versione dalle [release](https://github.com/bdbais/tonydefence-releases/releases/latest).
